## 공통 편집 패턴

### 1. 영상 구성 (시간 흐름 순)

| 단계 | 비율 | 내용 |
|---|---|---|
| **인트로** | 5~10% | 도착, 풍경 와이드, 차에서 내리는 모습, 짐 정리 시작 |
| **셋업** | 10~20% | 텐트/타프 설치 — **빠른 컷**으로 요약 (시작/중간/완성) |
| **요리/식사** | 20~30% | 재료 클로즈업 → 손동작 → 끓는 모습 → 플레이팅 → 한 입 |
| **여유/감상** | 20~30% | 불멍, 풍경, 음료/술, 책, 음악만 (B-roll 위주) |
| **밤/취침** | 10~15% | 야경, 텐트 안 조명, 잠자리 |
| **마무리** | 5~10% | 아침 풍경, 정리/철수 빠르게, 떠나는 차 와이드 |

### 2. 컷 길이

- **평균 컷 3~7초** — 길어도 10초 이내
- **B-roll 인서트 2~5초** — 풍경/디테일/장비 클로즈업
- **말소리/내레이션 컷은 길어도 OK** (15~30초까지) — 정보 전달이 우선
- 음악만 흐르는 구간도 **컷이 자주 떨어짐** (BGM 박자에 맞춰)

### 3. 샷 종류 (다양하게 섞기)

- **와이드샷**: 캠핑장 전경, 풍경, 장비 배치
- **미디엄샷**: 사람의 행동, 요리 과정
- **클로즈업**: 재료, 손동작, 음식 디테일, 불꽃, 물방울
- **매크로**: 음식 표면, 잔의 술, 비 떨어지는 소리

### 4. ASMR 사운드 활용

같은 화면이 길어도 **사운드가 변하면** 지루하지 않다:
- 칼-도마 소리 → 끓는 소리 → 지글지글
- 비 내리는 소리, 새 소리, 바람 소리
- 불 타는 소리, 장작 부서지는 소리
- **이런 ASMR 장면은 길이 가이드 적용 시 한 번 더 고려** — 사운드만으로 감상 가치 있음

### 5. 시그니처 패턴

- **불멍 장면**: 30~60초까지 길게 두고 BGM 또는 ASMR (예외적으로 길어도 OK)
- **요리 시퀀스**: 짧은 컷 5~10개로 빠르게 진행
- **풍경 인서트**: 식사/대화 사이사이 2~3초씩 끼워 넣기
- **반려동물 컷**: 짧지만 자주 (2~3초) — 분위기 환기

## AI 편집 시 적용 규칙

### 우선 KEEP (출력하지 마세요 = 자동 KEEP)

1. **불멍/모닥불 장면** — 길이가 길어도 보통 KEEP (감성 핵심)
2. **요리 클로즈업** — 짧고 다양하게
3. **풍경 와이드샷** — 도착/시작/엔딩에 1개씩
4. **반려동물/소품 컷** — 짧게
5. **말소리(★) 모든 장면**

### 우선 CUT 또는 PARTIAL

1. **셋업 과정 길게** — 시작 + 중간 + 완성 3컷만 PARTIAL
2. **반복적 정리/철수** — 시작/끝만
3. **차량 이동(말소리 없음)** — CUT
4. **저모션 정체 장면** — 아무 변화 없는 30초+ 정지 화면 CUT
5. **같은 활동 반복** — 가장 모션 활발한 1~2개만 KEEP

### PARTIAL 패턴 (한 컷 10초 이내 + 띄엄띄엄)

- 60초 셋업 → `keep_windows: [0, 3]` (시작 + 완성, 사이 30초 점프)
- 90초 풍경 → `keep_windows: [0, 4, 8]` (시작/중간/끝)
- 50초 요리(말소리 없음) → `keep_windows: [0, 4]` (재료 + 완성)
- 70초 여유 → `keep_windows: [0, 3, 6]` (등장 + 중간 + 마무리)

### 흐름 우선 원칙

- **인트로 → 활동 → 여유 → 마무리**의 큰 흐름이 깨지지 않도록
- 각 활동(요리/식사/불멍/풍경)이 **최소 1개씩**은 살아있어야 함
- 비슷한 컷이 너무 빠르게 반복되면 단조로움 → **다른 종류의 샷으로 변주**
