# 편집 스타일 — 사용자 + 한국 감성 캠핑 브이로그

레퍼런스: 사용자 수동 편집 분석 + **조조캠핑(@jojocamping)**, **서주랜드(@seojooland)**

## 사용자 편집 스타일 (실제 수동 편집 통계)

- **평균 컷 길이: 9초** (중간값 6초)
- **5초 미만 컷이 39%** — 매우 짧은 컷 빈번 사용
- 5~10초: 28%, 10초 이상: 34% (말소리 씬 추정)
- 결과 영상: 평균 20~30분
- **한 원본 영상에서 1~9개 컷** (평균 1.4개)
- **원본 70%만 사용** — 30%는 통째로 사용 안 함 (활용도 낮으면 과감히 cut)
- 영상의 시작/중간 부분을 자주 사용 (75%)

## 핵심 원칙

- **평균 9초 ± 3초 컷**, 5초 미만도 적극 사용
- **한 원본에서 여러 짧은 컷** 가능 (같은 라벨이라도 다른 부분이면 OK)
- **활용도 낮은 영상은 통째로 cut OK** — 모든 원본을 살릴 필요 없음
- **말소리(★) 씬도 길면 partial** — 말 사이 여백/대기 시간 cut
- 영상 시작/중간 부분을 우선 사용
- 장면 전환이 자주 일어나야 흐름이 살아남
- B-roll(풍경/디테일/장비) 2~5초씩 사이사이 끼움

## 영상 흐름 (참고)

인트로(도착/짐) → 셋업(요약) → 요리/식사 → 여유(불멍/풍경) → 밤 → 마무리(철수)

각 단계가 빠짐없이 있어야 흐름이 자연스러움.

## 시그니처

- **불멍/모닥불**: 분위기 핵심 — 짧게라도 반드시 포함
- **요리 클로즈업**: 재료 → 손동작 → 결과물 (각 5초 내외 컷)
- **반려동물/소품**: 짧게(2~3초) 자주
- **풍경 와이드**: 도착/엔딩에 1개씩

## 말소리 씬 처리

- **정보 가치 있는 발화**(장비 설명, 요리 해설, 감상 토크)는 보존
- **무의미 발화**(어어, 음, 침묵 사이) + 변화 없는 화면 = partial 또는 cut
- 말소리 씬이 30초+ 길면 **핵심 발화 윈도우만** keep, 사이 여백 빼기
