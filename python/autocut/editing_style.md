# 편집 스타일 — 사용자 + 한국 감성 캠핑 브이로그

레퍼런스: 사용자 수동 편집 분석 + **조조캠핑(@jojocamping)**, **서주랜드(@seojooland)**

## 절대 우선 규칙 3가지

### 1. 시간순 행동 흐름이 가장 중요
브이로그의 본질은 주인공이 시간순으로 무엇을 하는가입니다.
도착 → 셋업 → 요리 → 식사 → 불멍 → 취침 → 아침 → 철수의 흐름이 깨지지 않게.

### 2. 짧은 장면 + 잦은 전환 + 촬영 영상 최대 활용
- 평균 컷 9초 ± 3초 (5초 미만도 적극)
- 같은 화면이 길게 이어지면 시청자가 빠져나감
- 촬영 영상은 가능하면 모두 짧게라도 사용 (통째 cut 최소화)

### 3. 주제 설명 말은 흐름 보호
- 장비 설명, 요리 해설, 감상, 스토리텔링은 의미 단위가 끊기지 않게 keep
- 의성어/혼잣말/의미 없는 발화는 cut 가능

## 사용자 편집 스타일 (실제 수동 편집 통계)

- **평균 컷 길이: 9초** (중간값 6초)
- **5초 미만 컷이 39%** — 매우 짧은 컷 빈번 사용
- 5~10초: 28%, 10초 이상: 34% (말소리 씬 추정)
- 결과 영상: 평균 20~30분
- **한 원본 영상에서 1~9개 컷** (평균 1.4개)
- 영상의 시작/중간 부분을 자주 사용 (75%)

## 영상 흐름 (참고)

인트로(도착/짐) → 셋업(요약) → 요리/식사 → 여유(불멍/풍경) → 밤 → 마무리(철수)

## 시그니처

- **불멍/모닥불**: 분위기 핵심 — 짧게라도 반드시 포함
- **요리 클로즈업**: 재료 → 손동작 → 결과물 (각 5초 내외 컷)
- **반려동물/소품**: 짧게(2~3초) 자주
- **풍경 와이드**: 도착/엔딩에 1개씩
- **활동 클러스터** (셋업/요리 등 여러 영상 걸친 활동): 시간순 분배
  - 첫 영상: 활동 시작
  - 중간 영상들: 대표 컷
  - 마지막 영상: 활동 완성/마무리
