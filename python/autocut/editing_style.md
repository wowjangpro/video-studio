# 편집 스타일 — 한국 감성 캠핑 브이로그

레퍼런스: **조조캠핑(@jojocamping)**, **서주랜드(@seojooland)**

## 핵심 원칙

- **컷 평균 3~7초**, 최대 10초. 같은 화면이 10초 넘게 이어지면 시청자가 빠져나간다
- **장면 전환이 자주** 일어나야 흐름이 살아남
- 같은 활동(요리/셋업/풍경)이라도 **다른 앵글로 짧게 끊어** 보여줌
- 말소리/내레이션은 길어도 OK (정보 전달이 우선)
- B-roll(풍경/디테일/장비) 2~5초씩 사이사이 끼움

## 영상 흐름 (참고)

인트로(도착/짐) → 셋업(요약) → 요리/식사 → 여유(불멍/풍경) → 밤 → 마무리(철수)

각 단계가 빠짐없이 있어야 흐름이 자연스러움.

## 시그니처

- **불멍/모닥불**: 분위기 핵심 — 짧게라도 반드시 포함
- **요리 클로즈업**: 재료 → 손동작 → 결과물 (각 짧게 컷)
- **반려동물/소품**: 짧게(2~3초) 자주
- **풍경 와이드**: 도착/엔딩에 1개씩
